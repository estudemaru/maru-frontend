# Amostras de impressão

Os PDFs desta pasta foram exportados antes da revisão de 28/09/2026 que reúne
a apresentação de cada família e a escrita na mesma folha. Eles não representam
a compactação atual do livro nem o novo padrão de seleção por família.

A nova exportação e a inspeção visual dependem de executar novamente os testes
em `tests/e2e/print.spec.js`. A execução do navegador foi bloqueada pelo limite
de uso da revisão automática de aprovação; os arquivos anteriores foram
preservados, sem serem apresentados como PDFs atualizados.
