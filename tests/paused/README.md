# Contratos anteriores à fase Arcade

Cópias das suítes de 28/09, preservadas para reativar a trilha e os materiais de
atividades. Não são executadas pelo Playwright atual (`testDir: tests/e2e`).
As suítes ativas verificam os bloqueios de rota, os cinco jogos, as referências,
a persistência, autenticação e a impressão de repetições. Expectativas antigas
de home, neon, rodadas de cinco itens e curso aberto foram substituídas.

A trilha voltou em 29/09: `tests/e2e/journey.spec.js` cobre a trilha, a lição e o
jogo final. Os testes de lição daqui esperavam a tela de conclusão logo após as
perguntas e ficam como referência.
